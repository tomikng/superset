## Self-host notes
- **Action required before deploying:** upstream made the R2 / usercontent variables required at boot. Append the placeholders to the live `.env` on ms1 first (`ssh ms1 'bash -s' < deploy/env-add-r2-placeholders.sh`), or the API will not start after the deploy. Behaviour is unchanged: uploads and page publishing fail at the storage call, as they did with the Blob placeholder.
- `BLOB_READ_WRITE_TOKEN` and `BLAXEL_SANDBOX_IMAGE` are no longer read; the template drops them.
- Version bumped to 1.25.6 (desktop, host-service, cli) in lockstep. The host service stays tunnel v2 only (ms1 relay speaks v2 since 1.25.5).
- Backend: https://superset-api.tom-nguyen.dev · Update feed: https://superset-app.tom-nguyen.dev/releases
